## Version A (recommended, about 1,100 characters)

13 May 2027.

That is the day the main duties of India's Digital Personal Data Protection Act start to apply: clear privacy notices, real consent, security safeguards, breach reporting within 72 hours, and answers to people's data requests.

Most small firms have not started. Not because they do not care, but because nobody has told them, in plain English, what to do first.

So we built Wolftech Shield Suite.

Compliance Kit
- Answer one plain-English question per rule
- Get a readiness score and a prioritised gap list
- Every gap shows the exact section or rule, with a link to the Government's own text
- Six draft documents as PDF, ready for your lawyer to review

Cyber Health Check
- A scored security check mapped to CERT-In directions and guidance
- Passive checks of your own domain: SPF, DKIM, DMARC, certificate, headers
- Fixes ranked easiest first

Three rules we held ourselves to:
1. No invented law. If we could not verify a rule in a primary source, it is marked unverified and left out of the score.
2. Your data stays on your machine. No analytics. No third-party scripts.
3. It is a readiness tool, not legal advice. Every document is a draft for a qualified lawyer.

It also ships with an MCP server, so your AI assistant can run the same checks locally.

First profile: law firms. More to follow.

## Before posting

- The date is taken from the Gazette notification. It may be 14 May 2027 if publication is treated as
  14 November 2025; "13 May 2027" is the earlier, safer date. Keep it, or write "mid-May 2027".
- Do not write "DPDP compliant", "certified" or "guaranteed". The suite does not certify compliance.
- There is no hosted MCP endpoint. The MCP server runs on the user's own machine, so the "MCP link"
  must point to setup instructions (a public repository or the website page), not to a server URL.
- Screenshots must show only the fictional "Sample Law Associates" workspace.
